# Contribute

Thanks for taking an interest in this project.

## Ways to Contribute

- Improve the causal explanation in the notebook.
- Add another estimator for comparison.
- Improve the Django visualization.
- Add a new observational dataset.
- Improve documentation.
- Report reproducibility issues.

## Before Opening a Pull Request

1. Keep the repository lightweight.
2. Avoid GPU-only dependencies.
3. Keep the notebook as the main implementation.
4. Do not introduce `src/`, preprocessing modules, or unnecessary scripts.
5. Explain any change to the causal assumptions or estimation strategy.

## Pull Request

Please include:

- What changed?
- Why was it changed?
- How was it tested?
- Does it change the estimated treatment effect or assumptions?

Small, focused pull requests are preferred.
