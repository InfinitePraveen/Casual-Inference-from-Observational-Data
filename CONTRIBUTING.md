# Contributing

This repository is designed as a compact educational and interview portfolio project.

## Development Guidelines

- Prefer clear Python over unnecessary abstraction.
- Keep examples reproducible on a CPU-only computer.
- Keep data downloads small.
- Put analysis and experimentation in the notebook.
- Keep Django code limited to the demonstration interface.
- Document important causal assumptions.

## Reporting Issues

When reporting an issue, include your Python version, operating system, dependency versions, and the notebook cell or Django page where the problem occurs.
